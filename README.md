# XJRes - NTIRE 2026 Remote Sensing Infrared Image Super-Resolution Challenge

## 👥 Team Information
- **Team Name:** XJRes
- **Challenge:** NTIRE 2026 Remote Sensing Infrared Image Super-Resolution Challenge

## 📋 Overview
This repository contains the code implementation for our solution in the NTIRE 2026 Remote Sensing Infrared Image Super-Resolution Challenge.

## 🚀 Quick Start

### Installation
```bash

# Install dependencies
pip install -r requirements.txt
# predict
python test.py --model_id 3--test-dir [path] --save-dir [path]
```
Our model weights are provided via the link specified in: model_zoo/team03_HAT_PFT/team03_HAT_PFT.txt.

The first line of this file contains the Google Drive download link, and the second line provides the corresponding gdown command for downloading.
